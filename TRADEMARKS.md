# FloppaOS name and logo

The code in this repository is free software under the GPL-3.0-or-later ([LICENSE](LICENSE)). That licence is
about the code. It does not let you use FloppaOS's name, logo or artwork for your own project.

## What is not free to use

- The name **FloppaOS**, and names that could be mistaken for it.
- The **FloppaOS logo**: the orange caracal head with tufted ears, in any colour or size.
- FloppaOS's own artwork. These files are © KianFloppa, all rights reserved. They are in this repository only so
  that FloppaOS itself can be built; the GPL does not apply to them:
  - `installer/art/logo.svg`, `installer/art/welcome.svg`
  - `installer/calamares/branding/floppaos/logo.png`, `installer/calamares/branding/floppaos/welcome.png`
  - `look/assets/floppaos-start.svg`
  - pictures made from these files when FloppaOS is built (start button, `floppaos` icon, boot screen,
    boot menu and installer pictures)

## What you may do

- Use, study, change and share the code under the GPL-3.0-or-later.
- Say that your project is "based on FloppaOS" or "a fork of FloppaOS", and link to this repository.
- Use the name and show the logo when you write or talk about FloppaOS itself (articles, reviews, videos),
  as long as it does not look like FloppaOS made or approved your work.

## What you may not do without written permission

- Publish a fork, an ISO image, a package or a website under the name FloppaOS or a similar name.
- Use the FloppaOS logo or artwork in your own project or product.
- Make your project look official or endorsed by FloppaOS.

## If you fork FloppaOS

Pick your own name and logo, then replace FloppaOS's:

- the artwork files listed above;
- the name in `iso/airootfs/etc/os-release`, `iso/airootfs/etc/motd`, `iso/build.sh` (image name and boot
  menus), `installer/calamares/branding/floppaos/` and `packages/` (package names and descriptions).

Questions: open an issue in this repository.

Other names mentioned in this repository (Windows, Microsoft, CachyOS, Arch Linux, KDE, Plasma and others)
belong to their owners. FloppaOS is not affiliated with them.
