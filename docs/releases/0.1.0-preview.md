# FloppaOS 0.1.0 preview

> **No warranty.** FloppaOS is a free hobby project made by one person. Installing it is at your own risk.
> Back up your files first, especially if you install FloppaOS next to Windows.

The first public FloppaOS image: a free gaming Linux based on Arch Linux, with a Windows 11-style desktop on
pure black. This is a **preview**: it has been built and tested in virtual machines, not yet on many real PCs.
The full 0.1.0 comes after tests on real hardware.

## Download

- **[floppaos-0.1.0-preview-x86_64.iso](https://floppaos.pages.dev/download/floppaos-0.1.0-preview-x86_64.iso)** (2.5 GB), from [floppaos.pages.dev](https://floppaos.pages.dev/#download)
- SHA-256: `5c9f73e2d8cc2b2df71dd8c470cb047fef37c6a86b5079115e7112d1c1738e6b`
  - Windows (PowerShell): `Get-FileHash floppaos-0.1.0-preview-x86_64.iso`
  - Linux: `sha256sum floppaos-0.1.0-preview-x86_64.iso`

Needs a 64-bit PC that starts with UEFI, 2 GB memory to install (8 GB or more for games), 20 GB free disk and
an AMD Radeon graphics card (Intel and NVIDIA come later). Write the ISO to a USB stick of 4 GB or more, for
example with Rufus in DD Image mode, switch Secure Boot off for the stick, start from it and double-click
**Install FloppaOS**. Every step, also for a virtual machine: [install guide](https://github.com/KianFloppa/floppaos/blob/main/docs/install-guide.md).

## What is in it

- **The desktop you know:** start button far left, FloppaOS Start with search and pinned apps, a taskbar with a
  small clock, Windows shortcuts (Win+E, Win+D, Win+L, Win+Tab, Ctrl+Shift+Esc and more).
- **Pure black** desktop, start menu, lock and login screen, made for OLED screens.
- **Floppa games:** Floppa Setup installs the Floppa Launcher at the first login and pins it to the taskbar;
  every Floppa game has FloppaNet (F2).
- **Ready for games:** Vulkan, 32-bit support, MangoHud, GameMode and gamescope.
- **Installer** (Calamares) that can put FloppaOS next to Windows, with a "Before you start" page, tick boxes
  for the Floppa games and an optional **Secure Boot** setup, so Windows games that need Secure Boot keep working.
- **Boots like Windows:** the PC maker's logo with a spinner, no boot menu when FloppaOS is the only system.
- **Updates:** Arch Linux updates, and FloppaOS's own packages from a signed repository.
- **FloppaOS PC check:** a read-only report about graphics, sound, network, Bluetooth, controllers and Secure Boot.

Full list: [CHANGELOG.md](https://github.com/KianFloppa/floppaos/blob/main/CHANGELOG.md).

## Known issues

- Tested in virtual machines only. "Next to Windows" was tested with a stand-in Windows disk, not real Windows.
- Some online games with kernel anti-cheat only run on Windows: keep Windows and install FloppaOS next to it.
- The USB stick starts with Secure Boot switched off; the installed FloppaOS can run with it on.
- In a very slow virtual machine (one without hardware acceleration) the installer can end with "Installation
  failed: Could not unmount the root of the target system". Everything was written by then: restart, and
  FloppaOS starts normally. Fixed for the next build.

Problems: open an [issue](https://github.com/KianFloppa/floppaos/issues) with a photo or screenshot.
