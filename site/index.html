FloppaOS

A free gaming Linux with the desktop you know from Windows 11: a start button, a start menu with search, a taskbar and the same keyboard shortcuts. Everything is pure black, made for OLED screens.

Version 0.1.0 preview. Tested in virtual machines so far.

Download the preview Try the Setup Pack

What you get

The desktop you know
The start button sits on the far left. FloppaOS Start has search and pinned apps, the taskbar has a small clock, and Windows shortcuts like Win+E, Win+D, Win+L and Win+Tab work.
Pure black
The desktop, the start menu and the lock screen are pure black, so OLED pixels stay off. No night-light tint, no splash screen.
Floppa games built in
Floppa Setup installs the Floppa Launcher and pins it to the taskbar. The launcher installs and updates the Floppa games, and every Floppa game has FloppaNet: press F2 in a game.
Ready for games
Vulkan graphics, 32-bit support, MangoHud, GameMode and gamescope come installed.
Next to Windows
The installer can put FloppaOS next to Windows. Tick Secure Boot in the installer and FloppaOS starts with Secure Boot on, so Windows games that need it keep working.
Free and open source
The code is GPL-3.0 and on GitHub. FloppaOS is based on Arch Linux, so the system and the drivers stay up to date.

Try it now on CachyOS

Already using CachyOS with KDE Plasma? The Setup Pack gives it the FloppaOS look and Floppa Setup. Open Konsole and type:

git clone https://github.com/KianFloppa/floppaos.git
cd floppaos
./install.sh

Then log out and back in once. To go back to KDE's own look, type ./uninstall.sh in the same folder. The install guide has every step.

Download the FloppaOS ISO

No warranty. FloppaOS is a free hobby project made by one person. Installing it is at your own risk. Back up your files first, especially if you install FloppaOS next to Windows.

Version 0.1.0 preview, November 2026. It has been tested in virtual machines, not yet on many real PCs. What is in it: release notes.

Download the ISO (2.5 GB)

Check the download: its SHA-256 checksum must be
5c9f73e2d8cc2b2df71dd8c470cb047fef37c6a86b5079115e7112d1c1738e6b
On Windows type Get-FileHash floppaos-0.1.0-preview-x86_64.iso in PowerShell, on Linux sha256sum floppaos-0.1.0-preview-x86_64.iso.

To install, write it to a USB stick, for example with Rufus in DD Image mode, switch Secure Boot off for the stick, start the PC from it and double-click "Install FloppaOS". The install guide has every step, also for a virtual machine.

Good to know

  • FloppaOS and the Setup Pack come with no warranty. Use them at your own risk and back up your files first.
  • Some online games with kernel anti-cheat only run on Windows. Keep Windows and install FloppaOS next to it.
  • The USB stick starts with Secure Boot switched off. The installed FloppaOS can run with it on.
  • FloppaOS is made by one person and has been tested in virtual machines so far. The full 0.1.0, without "preview", comes after tests on real PCs.

Open source

The code is on GitHub under GPL-3.0: read it, build the ISO yourself, or send fixes. The name FloppaOS, the caracal logo and the artwork are not under the GPL and stay with KianFloppa, so forks need their own name and logo (TRADEMARKS.md).

The source code of every program in the ISO is online too: the source release has each package's full source, and source-code.md says where everything is.

Found a security problem? Please report it privately first: the contact is in security.txt.
